## Команди бота

## Reply-клавіатура бота

Джерело: `backend/app/bot/keyboards.py` → `main_menu_reply_keyboard`.

Для звичайного покупця: `🏠 Старт`, `🗂 Каталог`

Для адміністратора додається другий ряд:
`⚙️ Admin`, `📦 Товари`, `📑 Замовлення`

Для платформного адміна ще один ряд: `🛠 Платформа (admin)`

> Увага: у reply-клавіатурі замовлення позначені `📑`, а в інлайн-меню — `📋`.
> Це не помилка документації, так у продукті.

## Структура WebApp

### Верхній рівень — оболонка магазину

Джерело: `backend/app/api/shop_webapp.py` → `_build_shop_sections`.

Це **три** вкладки, а не вісім. Часта помилка в старих доках.

| id | Назва для адміна | Назва для покупця | Умова показу |
|---|---|---|---|
| `catalog` | `Каталог` | `Каталог` | модуль каталогу увімкнений |
| `orders` | `Замовлення` | `Мої замовлення` | модуль замовлень увімкнений |
| `account` | — | `Кабінет` | увімкнений кабінет покупця, лише не-адмінам |
| `admin_products` | `Керування` | — | лише адміну, за наявності модуля |

## Способи оплати

Джерело: `backend/app/domain/order_status.py` → `PaymentMethod`.

| Внутрішнє значення | Назва в налаштуваннях |
|---|---|
| `stripe` | `Stripe` (поле `Secret key`, ключі `sk_`/`rk_`, live або test) |
| `paypal` | `PayPal` (поля `Client ID`, `Secret`; Sandbox чи Live визначається сам) |
| `liqpay` | `LiqPay` |
| `monobank_merchant` | `plata by mono` (він же Monobank Merchant) |
| `link` | `Оплата за посиланням` |
| `bank_details` | `Оплата за реквізитами` |
| `cash_on_delivery` | `Накладений платіж` |

Поля в картці **Оплати клієнтів**: `Public key`, `Private key`,
`Merchant Token`, `Післяплата`, `Посилання для оплати`, `Текст реквізитів`,
кнопка `Зберегти оплату`.

Валюти магазину (PAY-EU 2026-10-28, кілька валют PAY-FX 2026-10-28): нагорі екрана `Оплати`
select `Основна валюта` (варіанти `Гривня (грн)`, `Євро (€)`, `Злотий (zł)`, `Долар США ($)`,
`backend/app/domain/money.py` → `CURRENCIES`), чекбокси `Покупці можуть платити в`
(основна позначена й заблокована), поле `Націнка до курсу НБУ, %` (0–20) і курс НБУ.
З 2026-10-29 усе це на окремому екрані `Валюта магазину` (рядок нагорі `Оплати` з підсумком «Ціни в: …» і «Покупці платять також у €, $» / «Одна валюта»; блоки `Основна валюта`, `Покупці можуть платити в`, `Курс`; кнопка `Зберегти`).
Ціни інших валют: курс НБУ (`fx_service.py`, оновлення щодня, старше 4 днів не
використовується) × (1 + націнка), округлення до цілого; власна ціна товару в полі
`Ціна, €` / `Ціна, $` / `Ціна, zł` у картці товару (блок `Ціна в інших валютах`) завжди
важливіша. Вітрина: кнопка валюти між пошуком і фільтрами (знак `₴`/`€`/`$`/`zł`, шторка
`Валюта` з назвами валют), лише коли валют більше однієї. Checkout: випадний список
`Валюта оплати` (`Оберіть валюту`, наперед нічого не обрано; способи оплати приховані з
підказкою `Спершу оберіть валюту оплати.`, доки покупець не обере); під гривневими
способами `Оплата в гривнях: …`; вибір такого способу переводить замовлення в гривню.
Замовлення фіксує ціни в усіх валютах, суму, валюту й курс при оформленні
(`order_pricing.py`). Зміна валюти закриває сесію Stripe, PayPal не захоплюється; поки
відкрита оплата LiqPay / plata by mono (24 год), зміна валюти заборонена.
`LiqPay`, `plata by mono`, `Оплата за посиланням` позначені `Лише для гривні`, коли гривні
немає серед прийнятих. Ціни при зміні основної валюти не перераховуються. Аналітика рахує
виторг в основній валюті (`total_base`).
Stripe і PayPal підтверджуються автоматично (повернення покупця, опитування статусу,
перевірка кожні 3 хв протягом 48 год).

Що бачить покупець на checkout (v3 з 2026-11-14, `webapp/delivery`):
`Оплатити карткою онлайн` (Stripe), `Оплатити через PayPal`,
`Оплатити онлайн через LiqPay`, `Оплатити онлайн через Monobank`,
`Оплата за посиланням`, `Банківські реквізити`, `Накладений платіж` (без емодзі й бейджів).
Підказки під назвою (`PAYMENT_SHORT_HINTS`): «Картка, Apple Pay, Google Pay» (Stripe, LiqPay, Monobank),
«Акаунт PayPal або картка», «Сторінка оплати від магазину», «Переказ за реквізитами»,
«Оплата під час отримання»; обраний спосіб показує повний опис замість підказки.
Нижня панель на телефоні: `До оплати` + сума і одна головна кнопка: `Перейти до оплати`
(онлайн), `Я оплатив(ла)` (реквізити, посилання), `Підтвердити замовлення` (післяплата).
Для реквізитів `Скопіювати реквізити`. `Оновити статус` лише після відкриття сторінки оплати.
Крок доставки: кнопка `Далі до оплати`, панель `Разом`; служби доставки списком із радіокнопками.
Поля (з 2026-11-14, раунд 2): іконки в полях ПІБ, телефон, e-mail, місто, відділення; телефон починається з коду країни
доставки (+380, +48, +49, +420, +421), незмінений код прибирається. Фото в рядку замовлення 64px (один товар).
Анімації в усіх розділах WebApp (натискання, меню, шторки, переходи); вимикаються системним «зменшити рух».

Торкніться фото, щоб кадрувати чи видалити, утримуйте — щоб змінити порядок.», кнопки `AI-асистент фото`, `AI-чернетки`; без фото — велика кнопка `Додати фото`); `Назва товару`; `Опис` (`необов'язково`); `Ціна` (поле `Ціна`, з перемикачем `Ціна зі знижкою` поля `Звичайна ціна` + `Ціна зі знижкою`, рядок «Покупці бачать … замість … · −N%»); `Категорія` (чіпи `Без категорії`, категорії, `+ Нова`; посилання `Також показувати в інших категоріях` → `Також показувати в`); `Варіанти й залишки` (перемикач `Відстежувати залишки`, `Чим відрізняються варіанти`: `Розмір` / `Колір` / `Об'єм` / `Вага` / `Інше`, колонки `Варіант` / `Залишок, шт.`, кнопки `−` `+`, поле `Ще варіант` + `Додати` (кілька через кому), підказки `+ XS`…, рядок «Разом N шт. · M у резерві»); `У каталозі` (`Активний`, `Показувати, коли немає в наявності`); митний блок для магазинів з доставкою за кордон; `Видалити товар` (лише в наявного).
- Дії з фото (дотик): `Кадрувати`, `Зробити обкладинкою`, `Покращити з AI`, `Видалити фото`, `Скасувати`. Порядок — утримати й перетягнути (мишею — просто перетягнути).
- Нижня панель: для нового завжди `Очистити` + `Зберегти товар`; для наявного лише після змін `Скасувати` + `Зберегти зміни`. Вихід зі змінами: «Вийти без збереження?».
- Перевірки під полями: «Вкажіть назву — так товар шукатимуть покупці.», ціна, «Звичайна ціна має бути більшою за ціну зі знижкою.», повтор варіанта; облік без варіантів — «…хоча б один варіант…» з діями `Додати «Стандарт»` і `Не рахувати залишки`.
- Варіант із резервом (неоплачені замовлення): «N у резерві під неоплачені замовлення. Назву змінити й видалити варіант можна після оплати чи скасування.» — назва лише для читання, видалити не можна (сервер теж відмовляє, `variant_reserved`). Збереження більше не обнуляє резерв.
- Перегляд: справжній магазин у рамці (`Як побачать покупці`, `Картка` / `Сторінка`), незбережений товар першим у сітці; дотик по картці відкриває сторінку.
- `Видалити товар` / `Видалити`: м'яке видалення (товар зникає з каталогу й списку, замовлення лишаються).

**Підписка v2 (2026-11-15, PR #44).** Екран `Підписка`: заголовок і статус, під ним одним рядком тариф і «Оплачено до…»; перемикач `Місяць` / `Рік` (−20%); тарифи списком (рядок цілком вибирає тариф, радіо праворуч, у поточного тарифу мітка «Ваш тариф»; цифри тарифу видно лише у вибраного, решта — через `Детальніше`); закріплена панель оплати: «<Тариф> · <період>», економія для річного, кнопка `Оплатити $N`. Нижче блок `Більше про підписку`: інструкція, `Документи та умови`, `Історія платежів`, `Доступ до магазину`, `Маєте питання?`. Раунд 2 (PR #45): `Детальніше` відкриває список усередині натиснутого тарифу (заголовок «Усе з <попередній>, плюс:» або «Що входить:», дві колонки без рамки, короткі факти ховаються); тизер «Готові шаблони магазину» прибрано.
- (2026-11-19) `Кнопки в шапці`: рядок `Профіль` (завжди увімкнений, неактивний перемикач) з'являється, коли увімкнені кабінети покупців. Попередній перегляд у `Вигляд` показує кнопку профілю так само, як у магазині.
